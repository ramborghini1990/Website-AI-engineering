- **Behaviour.** Till: 8 products, add / one more / one less / remove, pay cash or card; a sale lowers the stock, adds money in, appears as the newest sale. Cash flow: 4 key figures, 30-day balance line, 8-week money in/out bars, each chart an `<svg role="img">` with title + written description and its figures as a real table (native `<details>`, keyboard-focusable scroll region). Orders: reorder per supplier (low products not already on an open order), draft → sent → received; only receiving raises the stock and books the money out. Everything is buttons: no text box, no file input.
- **Storage.** One IndexedDB database in the visitor's browser; the first render is the seed (so SSR and no-JS show the sample), saved changes load right after hydration; "Start over" rebuilds the seed through the `DemoEngine` and erases the saved data. If IndexedDB is missing or throws, the demo works and says changes last until the page closes. What comes back from the browser is parsed with a strict Zod schema with caps; invalid → sample data.
