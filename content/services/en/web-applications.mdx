## From idea to a product that holds up

I build complete applications, from interface to data, in one readable codebase: customer portals, dashboards, internal tools, MVPs of new products. I work with TypeScript and Next.js and pick the simplest solution that solves the problem, not the most fashionable one.

## Quality you can check

Automated tests, accessibility checks against the WCAG 2.2 level AA guidelines and speed measurements on mid-range devices are part of the work, not a final phase. That way problems surface when they are cheap to fix.

## Built to last

The code is structured so that others can read and change it. I leave documentation, a test environment and a clear release procedure, so the product can keep growing without me. If you have an idea to build or an application to renew, [tell me about it](/contact).
